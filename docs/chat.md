# 聊天与记忆控制

在 DSH 或已接入的 QQ 对话中，用一句话直接控制记忆和主动聊天。明确控制会立即执行；普通聊天继续交给模型回答。

## 记住与忘记

| 说法 | 处理 |
|---|---|
| “记住，我喜欢简短直接的回答” | 立即写入明确偏好，不等待下一次批量提炼 |
| “忘掉我的住址” / “把我的住址忘掉” | 查找自己相关的记忆并删除 |
| “这件事别再记了” | 根据同会话中自己上一条话定位；定位不到时要求说清内容 |
| “记住，今天别开玩笑” | 保留本次对话的语气要求，不写成永久偏好 |

删除会同时撤下相关原话、派生条目或包含该事实的摘要，并清理画像与注入缓存。墓碑阻止自动提炼把已删除的内容写回来；以后明确要求重新记住时可以再写入。

请尽量说出主题，例如“忘掉我的住址”“忘掉我的生日”，避免多个主题混在一句控制里。群聊中按说话人定位自己的内容，不会把其他成员的同类事实一起删除。

## 主动聊天与事项

| 说法 | 处理 |
|---|---|
| “不要再主动找我” | 暂停主动消息，状态会保存 |
| “恢复主动聊天” / “可以主动找我聊天” | 解除暂停；仍需在设置页开启主动聊天 |
| “以后别提答辩” | 保存主题排除，后续主动消息避开该主题 |
| “答辩已经结束了” / “面试取消了” | 结束匹配的待办，不再围绕它跟进 |

主动聊天开关和排除主题由主人修改。生成草稿后又回复、取消事项或删除来源记忆，旧跟进会在投递前重新检查。主动聊天默认关闭；开启后默认试运行，只生成草稿。

## 人格与用户状态

- 人设卡定义长期性格、语气和称呼；明确且持续的偏好可以进入长期记忆。
- “今天别开玩笑”“我现在烦死了”等临时状态留在当前对话，不概括成永久性格。
- “我没拿到 offer”表达用户受挫；“我拿到 offer 了”表达用户的好消息。系统会给回复模型临时提示，避免把它们误当成对角色的夸骂或亲密度变化。
- “老板说你是废物”属于转述，“我朋友真聪明”评价第三人，“你真行”没有单独的反讽证据时按夸奖处理。

情绪分类默认使用规则，可在配置里选择 `appraisal.mode = "llm"`。复杂反讽、隐含主语和多重引用仍取决于分类器与回复模型。

## 会话范围

原话保留当前说话人与来源；提炼后的记忆继续带会话和可见范围。你在 QQ 上的主人私聊与 DSH 共用主人档案，群聊和其他人的私聊按各自范围召回。

自己的明确控制能直接处理自己的记忆；本机的记忆管理工具提供按条查看、删除和恢复。详见 [记忆说明](how-memory-works.md) 与 [HTTP API](http-api.md)。
