# 实测图表契约

核心结论：当前改进提高原文与项目归属的可靠性、减少不变画像的重复调用；完整长期模拟中是否保持召回以及增加多少提炼输入，必须由全部五组原始点共同检验。

采用 Python / matplotlib，工程定量网格；不使用双 Y 轴、显著性星号或虚构置信区间。颜色固定：旧版灰色、新版蓝色、SurfCore 橙色；数据不删行、不挑 seed。

1. 检索和项目归属：七类/汇总 Recall@5 点图，显示每类题数；同名项目本项目/外项目可见比例。检索比较使用同一组确定性词法向量，SurfCore 由外部适配器提供项目过滤。项目测试是重复合成场景，不代表独立真实项目样本。
2. 提炼和注入开销：全部五 seed 的前后配对点连线，分别用字符/万字符为单位；标记均值，不换算人民币。保留输入变长的结果。
3. 情绪与表达：所有检查点的效价/唤醒度轨迹、重启误差原始点和表达策略上限。效价平滑继承旧 PID；旧版不提供独立唤醒度。策略上限不能当作已生成消息量、实际 token 或真人感评分。旧版重启后的随机数未持久化，此处误差是本轮观测值。
4. 预算权衡：所有正预算点的完整答案记录/关键记录比例及估算上下文长度；0（关闭预算）的结果作为参考线。旧版没有 token 预算接口，固定字符装配作为参考。预算为软约束，不能画成硬上限。

导出：11–13 英寸宽，SVG（文字可编辑）及 300 dpi PNG；中文使用微软雅黑，缺失时使用系统已有中文字体。原始 JSON、CSV、聚合/缺失审计与图源码一并保留。图底注说明离线/合成场景、指标口径。

审计：完整执行清单及源码 hash 确认冻结；先对全部 CSV 进行列类型、缺失、范围、离群点和组数分析，再生成图。刻意缺失（旧版唤醒度、非重启检查点误差）单独说明。调用 audit_layout 检查文字/刻度裁切，再实际查看 PNG，修正后交付。
