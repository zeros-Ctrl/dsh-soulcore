# 情绪模型

情绪值的范围是 (0, 1)，0 是悲伤，1 是开心，两端都到不了。每次事件不会直接把心情改掉，而是：

1. **事件 + 孤独感 → 设定点**：被夸、被凶、道歉、项目成功……每种事件有一个冲击幅度（对数正态抽样，
   同样一件事有时影响大、有时小）；
2. **前置滤波**：设定点先平滑一道；
3. **PID + 情绪惯性**：实际心情按 PID 控制器跟过去，带抗积分饱和；
4. **限速**：每分钟最多变化 0.008，所以相邻两分钟之间几乎不会跳变；
5. **性格漂移**：长期的心情会慢慢改变基线（`tau_trait`），最后又会被先天基线拉回去（`tau_innate`）。

同一件事每次的冲击强度是随机抽样的，所以同样被冷落，有时是"低落"，有时只是"有点闷"。

## 事件

`praise`（夸）、`scold`（凶）、`apology`（道歉）、`gift`、`success`、`chat`、
`stranger_insult`、`ignored`、`responded`、`balance_low`、`balance_out`、`recharge`。

主动 QQ 消息在回复窗口结束后仍未得到回应时，会轻微影响状态；这依据实际发送记录和后续回复，不读取平台的“已读”状态。

聊天分类同时区分角色评价和用户状态：“我没拿到 offer”是用户受挫，“我拿到 offer 了”是用户的好消息，均不当成对角色的夸骂；引用和第三人评价也不直接影响亲密度。临时的用户状态只用于当轮回应提示。

## 标签

心情标签带滞回（`hyst=0.02`）：在边界附近不会来回跳。
公开 API 里 `label` 和 `describe` 给的是自然语言，不是数值。

## 和记忆、主动聊天的联动

- 主动聊天会参考心情：心情特别好或特别孤独时更愿意找你；
- 实际发送的主动消息未被回应时，她会低落一点，开口概率减半；连续 2 条没回就等你先开口；
- 草稿、发送失败的消息不算已发送，删除或取消跟进来源后会重新检查投递；
- 记忆检索不受心情影响（避免"心情差就什么都想不起来"这种假人格）。
