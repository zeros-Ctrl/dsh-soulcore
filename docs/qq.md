# QQ / B站 / 主动聊天

这部分是可选功能。QQ 场景下回复由后端自己调 DeepSeek 生成，所以**必须填写 API Key**。
请使用小号，在简介里声明是 AI，并遵守平台规则。

## 接入 QQ（NapCat + 正向 WebSocket）

soulcore 主动连 NapCat，收发同一条连接，断线自动重连，也不用给 soulcore 固定端口。
**全部在设置页里完成，不用改配置文件：**

1. 装 NapCat，用**小号**扫码登录。
2. 打开 NapCat WebUI（默认 `http://127.0.0.1:6099/webui`）→「网络配置」→ 新建「WebSocket 服务器」：
   Host `127.0.0.1`，端口 `3001`，消息格式 Array，设一个 Token，保存并启用。
3. DSH「设置 → 人格与记忆 → QQ 接入」：填**你的 QQ 号**、地址 `ws://127.0.0.1:3001` 和 Token，
   点「测试连接」，看到"连上了：机器人 QQ xxx"后打开「启用 QQ」，保存设置。

- **你的 QQ 号**：她会把这个号认成你，和 DSH 里的你共用 `core/people/owner` 这一份档案，
  私聊自动放行，QQ 私聊里也能聊起项目上的事；群里看不到项目记忆。
- **常驻运行**：设置页点「安装常驻（开机自动启动）」，会注册一个登录 Windows 时自动启动的计划任务。
  这样 DSH 关了她也在线，DSH 打开时直接连上她，不会多开。
  命令行等价操作：`python -I core/run.py -c <config.json> install-service` / `uninstall-service` / `service-status`。
- **单实例**：后端启动时先加锁再初始化，DSH 先读锁，能接入就不再起第二个进程。

旧的 HTTP 上报（`transport: "http"`）仍然保留，只能通过编辑 `config.json` 使用。

聊天中可直接说“记住……”“忘掉我的住址”“不要再主动找我”，详见 [聊天控制](chat.md)。普通回复只有在 OneBot 确认发送成功后才写入助手历史；限流或发送失败不会留下“她已经说过”的假记录。

## B站

后端同时也是一个 B站轮询器（带人工审核队列，遇到风控码会立即暂停），
在 `config.json` 里打开 `bilibili.enabled` 即可。

### 在 QQ 里让她刷 B站

需要另外装好 `dsh-bili-whale`，并在 `config.json` 里打开 `qq.bili.enabled`。
只用它的只读命令，不评论、不点赞、不收藏、不私信。

| 你说 | 她会 |
|---|---|
| "最近刷到啥视频了" | 说出最近在首页刷到的视频（后台每 3 小时自己刷一次） |
| "帮我在b站搜一下猫咪视频" | 当场去搜，挑几个结果说说（几秒钟） |
| "看看第二个讲了啥" / "帮我看看《某视频》" | 先回一句"等我看看"，读完字幕后再主动发一条讲内容 |

- **只在私聊里，只对你和白名单里的人**：群里不帮人搜、不帮人看，免得谁都能用你的 B站账号发请求。
- **搜索列表按用户保存**：“第二个”引用当前私聊用户自己的搜索结果；未有搜索记录时才用公开刷到的视频。搜索失败会清空自己的旧列表。
- **先发出第一句再跟进**：“等我看看”发送成功后才发视频总结，第一句失败或被新的看视频请求替换会取消旧跟进。
- **每小时有上限**：默认搜 10 次、看 5 个视频（`qq.bili.search_per_hour` / `video_per_hour`）。
- **读字幕需要 B站登录有效**：登录过期时字幕接口会假装"没有字幕"，她会照实说"登录过期了"。
  换 cookie：更新 `~/.bili-ai/credentials.json`，可以用 `node bili.mjs session` 检查。
- **她看不到画面、听不到声音**：没有字幕的视频只知道标题和简介。
- **搜索结果和字幕都是公开内容**，只在当次聊天里用，不会进入你在 DSH 里的编程会话。

## 主动聊天

接好 QQ 后，在设置页「主动聊天」里打开「让她主动找你聊天」。她只给**你**发私聊，永远不主动发群。

**她什么时候会找你：**

| 念头 | 例子 |
|---|---|
| 跟进 | 你说过"明天下午三点答辩"，第二天 17 点后问你答辩怎么样 |
| 接着聊 | 她上次问你的问题你一直没回，过几个小时再提起 |
| 关心 | 23 点以后你还在 DSH 里写代码；或者连续忙了 3 个多小时 |
| 分享 / 想你 | 心情特别好，或者很久没人理她 |

**她什么时候不会打扰你：**

- 勿扰时段内（默认 0:00–9:00）；
- 你刚在 QQ 上和她聊过；
- 你正在 DSH 里忙，这时只会发"关心"类的消息；
- 上一条还在等你回；
- 每天已经发够上限（默认 3 条），或者离上一条不到最小间隔（默认 3 小时）。

**和情绪联动：**

- 你回了，她会开心一点，也更愿意主动找你；
- 你没回，她会低落一点，开口的概率减半；
- 连续 2 条没回，就一直等你先开口。

**试运行（默认开）：**

- 只生成草稿，不真的发。草稿在设置页里看，可以发送或丢弃；
- 点「让她现在想一想」可以立刻试一次；
- 看满意了再关掉试运行。

生成消息需要 DeepSeek API Key。

可在私聊里说“不要再主动找我”暂停，或“恢复主动聊天”解除暂停；“以后别提答辩”排除主题，“答辩已经结束了”结束匹配事项。投递前会重新检查当前主人、暂停/勿扰状态和跟进来源，详见 [聊天控制](chat.md)。

## 相关配置

完整配置见 [config.md](./config.md)，重点：

| 配置 | 说明 |
|---|---|
| `owner.qq` | 你的 QQ 号（认成主人的关键） |
| `qq.enabled` / `qq.transport` / `qq.ws_url` | QQ 开关与连接方式 |
| `qq.group_whitelist` / `private_whitelist` / `group_known` | 群白名单、私聊白名单、群里的熟人 |
| `qq.sticker.*` | 表情包 |
| `qq.bili.*` | 在 QQ 里刷 B站、搜视频、读字幕 |
| `bilibili.enabled` / `auto_send` | 独立 B站轮询与自动回复 |
| `initiative.*` | 主动聊天（默认关闭、默认试运行） |
